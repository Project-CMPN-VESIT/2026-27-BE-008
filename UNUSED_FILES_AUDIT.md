# FinPilot: unused / unnecessary files audit

Generated 2026-10-28 on `main` at `30a711f`. **Nothing was deleted.** This is a review list only.

How it was checked
- Frontend: every file under `src/` was searched for imports from other files (Next.js entry files `page/route/layout` excluded); `public/` assets were searched by file name; API routes were searched for callers.
- Backend: a static import graph was walked from `web/api.py`, `web/cyro_skill.py`, `baskets/` and `cyro_chat/`. Modules the web app never reaches are listed. Modules loaded dynamically (for example `web/cyro_engine/adapters/*`, loaded through `importlib` by the context builder) were treated as **used**.
- Confidence: **High** = no reference anywhere. **Medium** = not used by the FinPilot web app but belongs to another entry point (the original CLI). **Low** = looks unused but could be wanted for another reason (submission, history).

## E. Security issue found while auditing (not about unused files)

- `.env` and `india-trade-cli/.env` are **tracked in git** and contain API-key and secret-named variables (10 and 8 entries). They are on the remote. Rotate those keys, run `git rm --cached .env india-trade-cli/.env`, and keep only `.env.example`. The repo already has an `.env.example` in `india-trade-cli/`.
